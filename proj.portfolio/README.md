# Раздел 4: (Бонус-практика) Практика с сайтом-портфолио

Практическая работа по созданию сайта портфолио.

Используется:

- Vite
- React
- TypeScript
- SCSS

Структура проекта:

- `src/`
  - `components/`
    - `ui/` — атомы/молекулы, полностью независимые (`Button`, `Card`, `Icon`, `List` ...)
    - `blocks/` — секции проекта (`Header`, `Hero`, `About`, `Projects`, `Contact`) — используют `ui/*`
    - `layout/` — общие layout-компоненты (Container, Page, HeaderLayout)
    - `index.ts` — barrel-экспорт (опционально)
  - `data/` — контент для блоков (`projects.ts`, `about.ts`)
  - `hooks/` — кастомные React-хуки (логика, связанная с React)
  - `utils/` — чистые функции и помощники, не зависящие от React
  - `types/` — TS-типизация и интерфейсы
  - `styles/` — `variables.scss`, `main.scss` (глобально)
  - `App.tsx`, `main.tsx`

Преимущества:

- `ui/*` — можно переиспользовать в других проектах;
- `blocks/` — концентрируют именно проектный контент/структуру и импортируют `ui/*`;
- `data/*` — отделяет контент от презентации (легко заменить/локализовать);
- ясные barrel-экспорты упрощают импорты.

Короткие советы по импорту/экспортам:

- Barrel в `src/components/index.ts`: экспортировать `ui` и `blocks`, чтобы импорт делать просто: `import { Button } from 'src/components';`
- Держите глобальные переменные SCSS в `style.scss` `/src/styles/variables.scss` и импортируйте их в модульные scss при необходимости.
- Контент (`src/data`) можно в итоге получать из CMS/MD/JSON, что не затронет UI.
