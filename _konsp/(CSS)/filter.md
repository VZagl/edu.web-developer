# CSS3-фильтры

> [!NOTE]
> В этом конспекте собраны основные сведения о CSS-фильтрах: синтаксис, примеры, особенности применения и рекомендации по производительности.

## Кратко — что это такое

> [!TIP]
> CSS-фильтры позволяют визуально изменять внешний вид элементов (изображений, блоков) на стороне клиента с помощью эффектов вроде размытия, изменения яркости, контраста и т.д. Это — быстрый способ сделать эффект без изменения исходного изображения. Фильтры можно добавлять не только к изображениям, но и к любым непустым элементам.

## Синтаксис

Основное свойство:

```css
/* Простейший синтаксис */
selector {
	filter: none | <filter-function-list>;
}
/*
	<filter-function-list> — одна или несколько функций фильтра,
	разделённых пробелом, например: blur(4px) brightness(0.8) contrast(120%)
*/
```

Поддерживаемые функции (список с кратким описанием):

- `blur(<length>)` — размытие по Гауссу. Например: `blur(4px)`.
- `brightness(<number | %>)` — яркость, `1` (или `100%`) — без изменений, меньше — темнее, больше — ярче.
- `contrast(<number | %>)` — контраст, `1` — без изменений.
- `drop-shadow(<offset-x> <offset-y> <blur-radius> <color>)` — тень, похожа на `box-shadow`, но применяется как фильтр.
- `grayscale(<number | %>)` — перевод в оттенки серого (`1` / `100%` — полностью).
- `hue-rotate(<angle>)` — поворот цветового тона, принимает `deg`.
- `invert(<number | %>)` — инвертирует цвета.
- `opacity(<number | %>)` — делает элемент прозрачнее.
- `saturate(<number | %>)` — насыщенность цветов.
- `sepia(<number | %>)` — сепия-эффект.
- `url(<url>)` — использование SVG-фильтра по ID/URL.

> [!NOTE]
> Значения могут приниматься как в процентах, так и в числах (в документации уточните ожидаемый формат для конкретной функции).

## Порядок и комбинация фильтров

- Функции фильтра перечисляются через пробел и применяются слева направо.
- Порядок может влиять на финальный результат (например, `blur` до/после `contrast` даст разный визуальный эффект).

Пример комбинирования:

```css
.card img {
	filter: grayscale(50%) blur(2px) contrast(120%);
}
```

## Примеры

1. Простой эффект размытия и затемнение:

```css
.hero-bg {
	filter: blur(6px) brightness(0.7);
}
```

2. Эффект при наведении:

```css
.photo {
	transition: filter 250ms ease;
}
.photo:hover {
	filter: none;
}
```

3. Использование drop-shadow:

```css
.logo {
	filter: drop-shadow(2px 4px 6px rgba(0, 0, 0, 0.5));
}
```

## SVG-фильтры через `url()`

Можно использовать сложные SVG-фильтры:

```html
<svg width="0" height="0" style="position:absolute">
	<filter id="myFilter">
		<!-- SVG filter primitives -->
		<feGaussianBlur stdDeviation="3" />
	</filter>
</svg>
```

```css
/* применить к элементу */
.element {
	filter: url(#myFilter);
}
```

## Производительность и рекомендации

> [!WARNING]
> Фильтры (особенно `blur` и сложные SVG-фильтры) могут быть тяжёлыми для рендеринга и влиять на производительность, особенно на мобильных устройствах.

- Старайтесь избегать применения размытия к большим областям или часто анимируемым элементам.
- Для анимаций используйте `transform` и `opacity`, когда это возможно — GPU обычно оптимизирует эти свойства лучше.
- Если собираетесь анимировать `filter`, добавьте `will-change: filter` для подготовки, но используйте осторожно — он сам по себе может привести к увеличенному потреблению памяти.
- Предпочитайте простые CSS-фильтры вместо сложных SVG-фильтров, если эффект не требует специфики SVG.

## Поддержка браузеров

> [!NOTE]
> Большинство современных браузеров поддерживают стандартные CSS-фильтры, но стоит проверить конкретные функции (например, `drop-shadow` или `url()` с SVG) в целевых условиях.

- Если нужна полная совместимость со старыми браузерами — используйте запасные решения на стороне сервера (предварительно обработанные изображения) или прогрессивное улучшение.

## Полезные практики

- Тестируйте производительность на реальных устройствах.
- Для статичных эффектов — лучше подготовить изображение заранее (серверная генерация) и отдавать пользователю оптимизированный файл.
- Для декоративных эффектов используйте небольшие значения размытия и минимальное число функций фильтра.
