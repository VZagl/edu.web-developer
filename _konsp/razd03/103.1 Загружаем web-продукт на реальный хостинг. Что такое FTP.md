# 103.1 Загружаем web-продукт на реальный хостинг. Что такое FTP

> [!IMPORTANT]
> Браузер кэширует файлы.
> После загрузки новых файлов на сервер может случиться ситуация, когда у пользователей не отображаются изменения.
> Чтобы появились изменения необходимо очистить кэш браузера у пользователя.
> **Это проблема!**
> Причина: браузер хранит копии файлов (HTML, CSS, JS, изображения) для ускорения загрузки сайта, и может не заметить, что на сервере появились новые версии.
>
> Решения:
>
> - Использовать версионирование файлов (например, добавлять `?v=2` к ссылкам на CSS/JS).
> - Менять имена файлов при обновлении (например, `style.v2.css`).
>   - Vite при каждом `build` генерирует новое имя файлов (добавляет хэш файла к названию), что автоматически решает эту проблему.
> - Настраивать заголовки `Cache-Control` на сервере для управления сроком хранения кэша.
> - Сообщать пользователям о необходимости обновить страницу с помощью `Ctrl+F5` или очистить кэш.

## [Vercel][1]

Vercel — это современный облачный хостинг для фронтенд-проектов (React, Next.js, Vite и др.), который позволяет деплоить сайты и приложения буквально в несколько кликов.

**Преимущества Vercel:**

- Автоматический деплой из репозитория (GitHub, GitLab, Bitbucket)
- Бесплатный тариф для небольших проектов
- Мгновенное обновление сайта после пуша в репозиторий
- HTTPS и CDN по умолчанию
- Поддержка SSR/SSG для Next.js

**Как разместить проект на Vercel:**

1. Зарегистрируйтесь на [vercel.com][1]
2. Подключите свой репозиторий (GitHub, GitLab, Bitbucket)
3. Выберите проект и нажмите "Deploy"
4. После деплоя получите ссылку на ваш сайт

**Особенности:**

- Для Vite/React/Next.js ничего настраивать не нужно — Vercel сам определяет тип проекта
- Все обновления происходят автоматически после каждого коммита
- Можно подключить собственный домен

**Документация:**
