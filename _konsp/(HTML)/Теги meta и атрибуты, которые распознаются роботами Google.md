## Что такое теги `meta`?

Теги `meta` – это HTML-код, предназначенный для предоставления поисковым системам и другим клиентам дополнительной информации о веб-странице. Если клиент не способен обработать определенные теги `meta`, он просто проигнорирует их. Теги `meta` добавляются в раздел `<head>` HTML-кода.

**Полный пример структуры:**

```html
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8" />
		<meta
			name="description"
			content="Author: A.N. Author, Illustrator: P. Picture, Category: Books, Price: £9.24, Length: 784 pages"
		/>
		<meta
			name="google-site-verification"
			content="+nxGUDJ4QpAZ5l9Bsjdi102tLVC21AIh5d1Nl23908vVuFHs34="
		/>
		<title>Example Books - high-quality used books for children</title>
		<meta name="robots" content="noindex,nofollow" />
	</head>
</html>
```

> **Важно для CMS:** Если вы пользуетесь системой управления контентом (например, Wix, WordPress или Blogger), найдите в ней инструменты для редактирования раздела `<head>` или добавления метатегов.

## Основные теги `meta`, поддерживаемые Google

1. **description**:

   - Пример: `<meta name="description" content="Описание страницы">`
   - Используется для предоставления краткого описания страницы, которое может отображаться в результатах поиска.

2. **robots и googlebot**:

   - Примеры:
     - `<meta name="robots" content="noindex,nofollow">`
     - `<meta name="googlebot" content="noindex,nofollow">`
   - **Назначение:** Указывают поисковым системам, как следует сканировать и индексировать веб-страницы
   - **Различия:**
     - `robots` понятен всем поисковым роботам
     - `googlebot` предназначен только для Google
   - **Приоритет:** Если заданы разные настройки, применяются наиболее строгие ограничения
   - **Популярные значения:**
     - `noindex` - не индексировать страницу
     - `nofollow` - не переходить по ссылкам
     - `noarchive` - не создавать кешированную копию
     - `nosnippet` - не показывать описание в результатах поиска

3. **notranslate**:

   - Пример: `<meta name="googlebot" content="notranslate">`
   - **Назначение:** Запрещает автоматический перевод страницы в результатах поиска Google
   - **Подробности:** Если в результатах поиска есть страницы на языках, которые не подходят пользователю, их ссылки-заголовки и описания могут автоматически переводиться. Этот тег отключает данную функцию.

4. **nopagereadaloud**:

   - Пример: `<meta name="google" content="nopagereadaloud">`
   - Запрещает преобразование текста в речь продуктами Google.

5. **google-site-verification**:

   - Пример: `<meta name="google-site-verification" content="...">`
   - **Назначение:** Используется для подтверждения прав собственности на сайт в Google Search Console
   - **Важно:**
     - Значения атрибутов `name` и `content` должны точно соответствовать указанным в Search Console (включая регистр символов)
     - Формат тега (XHTML или HTML) значения не имеет
     - Размещается на странице самого верхнего уровня

6. **Content-Type и charset**:

   - Примеры:
     - `<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">`
     - `<meta charset="UTF-8">` (современный способ)
   - **Назначение:** Определяют тип контента и набор символов страницы
   - **Рекомендации:**
     - Значение атрибута `content` в теге `http-equiv` нужно заключить в кавычки
     - По возможности используйте набор символов Unicode/UTF-8
     - Предпочтительнее короткая форма `<meta charset="UTF-8">`

7. **refresh**:

   - Пример: `<meta http-equiv="refresh" content="5;url=https://example.com">`
   - **Назначение:** Перенаправляет пользователя на новый URL через определенное время
   - **Ограничения:**
     - Поддерживается не всеми браузерами
     - Может вводить пользователей в заблуждение
     - Google рекомендует использовать вместо него серверную переадресацию 301

8. **viewport**:

   - Пример: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
   - **Назначение:** Предоставляет браузеру информацию с указаниями по обработке страницы на мобильном устройстве
   - **Значение:** Наличие этого тега говорит Google о том, что страница оптимизирована для мобильных устройств
   - **Популярные параметры:**
     - `width=device-width` - ширина равна ширине устройства
     - `initial-scale=1.0` - начальный масштаб 100%
     - `user-scalable=no` - запрет масштабирования пользователем

9. **rating**:
   - Примеры:
     - `<meta name="rating" content="adult">`
     - `<meta name="rating" content="RTA-5042-1996-1400-1577-RTA">`
   - **Назначение:** Указывает, что страница содержит контент для взрослых
   - **Результат:** Страница не будет показываться в Google при использовании Безопасного поиска

## Атрибуты HTML-тегов

**Атрибуты HTML-тегов** – это дополнительные значения HTML-тегов, в которых содержатся настройки родительского тега. Например, атрибут `href` тега `<a>` содержит настройки ресурса, на который указывает ссылка.

### Поддерживаемые Google атрибуты:

1. **Атрибуты `src` и `href`** - позволяют обнаруживать различные ресурсы (изображения, URL)
2. **Атрибуты `rel`** - позволяют маркировать исходящие ссылки
3. **Атрибут `data-nosnippet`** - исключает части HTML-страниц из фрагментов (для тегов `div`, `span`, `section`)

Пример использования `data-nosnippet`:

```html
<div data-nosnippet>Этот текст не будет включен в фрагменты поиска</div>
```

## Рекомендации и важные моменты

### Общие рекомендации:

- Google распознает теги `meta` в формате HTML и XHTML независимо от используемого кода
- Код в разделе `<head>` должен отвечать стандартам HTML с правильными закрывающими тегами
- Как правило, регистр символов в тегах `meta` не учитывается (исключение: `google-site-verification`)
- Можно использовать любые другие теги `meta` для своих задач - Google просто проигнорирует неизвестные ему теги

### Работа с JavaScript:

- **Не рекомендуется** внедрять или изменять теги `meta` с помощью JavaScript
- Если всё же используете JavaScript для работы с метатегами, действуйте осторожно и обязательно проверяйте результаты

### Инструменты для проверки:

- Используйте [инструмент проверки URL](https://support.google.com/webmasters/answer/9012289?hl=ru) для проверки тегов `meta` и атрибутов на страницах своего сайта
- Проверяйте корректность тегов после любых изменений
