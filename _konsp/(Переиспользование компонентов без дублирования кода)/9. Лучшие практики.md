## 9. Лучшие практики и рекомендации

### 9.1 Принципы проектирования компонентов

**1. Единственная ответственность (Single Responsibility Principle)**

```scss
// ❌ Плохо - компонент отвечает за слишком многое
.user-card {
	border-radius: 8px;
	// Стили карточки
	padding: 20px;

	// Стили кнопки (должно быть отдельным компонентом)
	&__button {
		background: blue;
		padding: 10px;
	}

	// Стили формы (должно быть отдельным компонентом)
	&__form {
		margin-top: 20px;
	}
}

// ✅ Хорошо - каждый компонент имеет одну ответственность
.card {
	border-radius: 8px;
	background: white;
	padding: 20px;
}

.btn {
	border-radius: 4px;
	padding: 10px 20px;
	// ...
}

.form {
	// Отдельные стили для формы
}
```

**2. Композиция вместо наследования**

```html
<!-- ❌ Плохо - сложная иерархия наследования -->
<div class="card card--user card--user-premium">
	<!-- контент -->
</div>

<!-- ✅ Хорошо - композиция компонентов -->
<div class="card">
	<div class="card__header">
		<div class="user-avatar user-avatar--premium">
			<!-- аватар -->
		</div>
		<div class="user-info">
			<!-- информация -->
		</div>
	</div>
	<div class="card__body">
		<!-- контент -->
	</div>
</div>
```

**3. Прогрессивное улучшение**

```css
/* Базовые стили работают без JavaScript */
.dropdown {
	position: relative;
}

.dropdown__content {
	display: none; /* Скрыто по умолчанию */
	position: absolute;
	top: 100%;
}

/* Показываем при наведении как fallback */
.dropdown:hover .dropdown__content {
	display: block;
}

/* Улучшение через JavaScript */
.dropdown--enhanced {
	/* Более сложная логика доступна только с JS */
}

.dropdown--enhanced .dropdown__content {
	display: block;
	visibility: hidden;
	opacity: 0;
	transition: all 0.3s ease;
}

.dropdown--enhanced.is-open .dropdown__content {
	visibility: visible;
	opacity: 1;
}
```

// Ленивая загрузка тяжёлых компонентов
class ComponentLoader {
	static async loadComponent(name) {
		if (this.cache.has(name)) {
			return this.cache.get(name);
		}

		const { default: Component } = await import(
			`./components/${name}/${name}.js`
		);
		this.cache.set(name, Component);
		return Component;
	}

	static cache = new Map();
}

// Инициализация компонентов при появлении в viewport
const observer = new IntersectionObserver((entries) => {
	entries.forEach((entry) => {
		if (entry.isIntersecting) {
			const componentName = entry.target.dataset.component;
			ComponentLoader.loadComponent(componentName).then(
				(Component) => new Component(entry.target)
			);
			observer.unobserve(entry.target);
		}
	});
});

// Отслеживаем элементы с атрибутом data-component
document
	.querySelectorAll('[data-component]')
	.forEach((el) => observer.observe(el));
```

// Генерация критических стилей на лету
class CriticalStylesManager {
	constructor() {
		this.styleSheet = document.createElement('style');
		document.head.appendChild(this.styleSheet);
	}

	addCriticalStyles(componentName, styles) {
		this.styleSheet.textContent += `
			/* Critical styles for ${componentName} */
			${styles}
		`;
	}

	loadComponentStyles(componentName) {
		// Проверяем, загружены ли стили
		if (!this.isStylesLoaded(componentName)) {
			// Добавляем критические стили немедленно
			this.addCriticalStyles(
				componentName,
				this.getCriticalStyles(componentName)
			);

			// Загружаем полные стили асинхронно
			this.loadFullStyles(componentName);
		}
	}

	getCriticalStyles(componentName) {
		// Возвращаем минимальные стили для предотвращения скачков
		const criticalMap = {
			modal: '.modal { position: fixed; z-index: 1000; }',
			dropdown: '.dropdown { position: relative; }',
			card: '.card { display: block; }',
		};

		return criticalMap[componentName] || '';
	}
}
```

**2. Управление фокусом**

```javascript
class FocusManager {
	static trapFocus(element) {
		const focusableElements = element.querySelectorAll(
			'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
		);

		const firstElement = focusableElements[0];
		const lastElement = focusableElements[focusableElements.length - 1];

		const handleTabKey = (e) => {
			if (e.key === 'Tab') {
				if (e.shiftKey) {
					if (document.activeElement === firstElement) {
						e.preventDefault();
						lastElement.focus();
					}
				} else {
					if (document.activeElement === lastElement) {
						e.preventDefault();
						firstElement.focus();
					}
				}
			}
		};

		element.addEventListener('keydown', handleTabKey);
		firstElement?.focus();

		return () => element.removeEventListener('keydown', handleTabKey);
	}
}
```

### 9.5 Документирование компонентов

**1. Автогенерация документации**

```javascript
// scripts/generate-docs.js
import fs from 'fs/promises';
import path from 'path';
import { glob } from 'glob';

class ComponentDocGenerator {
	async generateDocs() {
		const components = await this.scanComponents();
		const docsHTML = await this.generateHTML(components);
		await fs.writeFile('docs/components.html', docsHTML);
	}

	async scanComponents() {
		const componentPaths = await glob('src/components/**/*.js');
		const components = [];

		for (const componentPath of componentPaths) {
			const component = await this.parseComponent(componentPath);
			if (component) components.push(component);
		}

		return components;
	}

	async parseComponent(filePath) {
		const content = await fs.readFile(filePath, 'utf-8');

		// Парсим JSDoc комментарии
		const classMatch = content.match(
			/\/\*\*([\s\S]*?)\*\/[\s\S]*?class\s+(\w+)/
		);
		if (!classMatch) return null;

		const docComment = classMatch[1];
		const className = classMatch[2];

		// Извлекаем описание
		const description = this.extractDescription(docComment);

		// Извлекаем примеры использования
		const examples = this.extractExamples(docComment);

		// Извлекаем параметры
		const params = this.extractParams(docComment);

		return {
			name: className,
			description,
			examples,
			params,
			filePath,
		};
	}

	extractDescription(docComment) {
		const match = docComment.match(/\*\s*([^@]*?)(?:\*\s*@|$)/s);
		return match ? match[1].trim() : '';
	}

	extractExamples(docComment) {
		const exampleMatches = [
			...docComment.matchAll(/\*\s*@example\s*([\s\S]*?)(?=\*\s*@|\*\/)/g),
		];
		return exampleMatches.map((match) => match[1].trim());
	}

	extractParams(docComment) {
		const paramMatches = [
			...docComment.matchAll(/\*\s*@param\s*\{([^}]+)\}\s*(\w+)\s*-?\s*(.*)/g),
		];
		return paramMatches.map((match) => ({
			type: match[1],
			name: match[2],
			description: match[3],
		}));
	}
}
```

	'1.0.0->1.1.0': (element) => {
		// Миграция с версии 1.0.0 на 1.1.0
		if (element.classList.contains('btn-large')) {
			element.classList.remove('btn-large');
			element.classList.add('btn--large');
		}

	'1.1.0->2.0.0': (element) => {
		// Миграция с версии 1.1.0 на 2.0.0
		const oldClasses = ['btn--primary', 'btn--secondary'];
		const newClasses = ['button--primary', 'button--secondary'];

		oldClasses.forEach((oldClass, index) => {
			if (element.classList.contains(oldClass)) {
				element.classList.remove(oldClass);
				element.classList.add(newClasses[index]);
			}
		});
	},
};

// utils/deprecation.js
class DeprecationManager {
	static warnings = new Set();

	static warn(componentName, feature, version, alternative) {
		const key = `${componentName}.${feature}`;

		if (!this.warnings.has(key)) {
			console.warn(
				`⚠️ DEPRECATION WARNING: ${componentName}.${feature} устарел с версии ${version}. ` +
					`Используйте ${alternative} вместо этого.`
			);
			this.warnings.add(key);
		}
	}

	static checkUsage(element) {
		// Проверяем использование устаревших классов
		const deprecatedClasses = {
			'btn-large': { version: '1.1.0', alternative: 'btn--large' },
			'card-rounded': { version: '1.2.0', alternative: 'card--rounded' },
		};

		Object.entries(deprecatedClasses).forEach(([className, info]) => {
			if (element.classList.contains(className)) {
				this.warn('CSS', className, info.version, info.alternative);
			}
		});
	}
}

### 9.7 Мониторинг и аналитика компонентов

**1. Отслеживание использования компонентов**

```javascript
// analytics/ComponentTracker.js
class ComponentTracker {
	constructor(config = {}) {
		this.config = {
			enabled: true,
			endpoint: '/api/component-analytics',
			batchSize: 10,
			...config,
		};

		this.queue = [];
		this.observer = new IntersectionObserver(
			this.handleIntersection.bind(this)
		);
	}

	init() {
		if (!this.config.enabled) return;

		// Отслеживаем все компоненты
		document.querySelectorAll('[data-component]').forEach((element) => {
			this.observer.observe(element);
			this.trackComponentMount(element);
		});

		// Отправляем данные при закрытии страницы
		window.addEventListener('beforeunload', () => this.flush());
	}

	trackComponentMount(element) {
		const componentName = element.dataset.component;
		const timestamp = Date.now();

		this.addToQueue({
			event: 'component_mount',
			component: componentName,
			timestamp,
			url: window.location.pathname,
			viewport: {
				width: window.innerWidth,

				height: window.innerHeight,
			},
		});
	}

	handleIntersection(entries) {
		entries.forEach((entry) => {
			if (entry.isIntersecting) {
				this.trackComponentView(entry.target);
				this.observer.unobserve(entry.target);
			}
		});
	}

	trackComponentView(element) {
		const componentName = element.dataset.component;

		this.addToQueue({
			event: 'component_view',
			component: componentName,
			timestamp: Date.now(),
			position: {
				top: element.offsetTop,
				left: element.offsetLeft,
			},
		});
	}

	addToQueue(data) {
		this.queue.push(data);

		if (this.queue.length >= this.config.batchSize) {
			this.flush();
		}
	}

	async flush() {
		if (this.queue.length === 0) return;

		try {
			await fetch(this.config.endpoint, {
				method: 'POST',
				headers: {
					'Content-Type': 'application/json',
				},
				body: JSON.stringify(this.queue),
			});

			this.queue = [];
		} catch (error) {
			console.error('Ошибка отправки аналитики компонентов:', error);
		}
	}
}

// Инициализация
const tracker = new ComponentTracker();
document.addEventListener('DOMContentLoaded', () => tracker.init());
```

## Заключение

Использование компонентного подхода в HTML+CSS+SCSS проектах позволяет создавать масштабируемые, поддерживаемые и переиспользуемые интерфейсы. Ключевые принципы успешной реализации:

### 🎯 Основные принципы:

1. **Модульность** - каждый компонент решает одну задачу
2. **Переиспользование** - компоненты легко адаптируются под разные контексты
3. **Масштабируемость** - система растёт без усложнения архитектуры
4. **Поддерживаемость** - код легко читается и модифицируется

### 🛠 Технические решения:

- **BEM методология** для именования CSS классов
- **SCSS миксины** для переиспользования стилей
- **CSS Custom Properties** для гибкой настройки
- **Web Components** для сложной интерактивности
- **Модульная архитектура** JavaScript

### 📱 Адаптивность:

- **Mobile-first подход** в разработке
- **Гибкие сетки** и **контейнерные запросы**
- **Адаптивная типографика** и **изображения**
- **Прогрессивные улучшения** для всех устройств

### ⚡ Производительность:

- **Критический CSS** для быстрой загрузки
- **Ленивая загрузка** компонентов
- **Оптимизация изображений** и **SVG спрайты**
- **Минификация** и **сжатие** ресурсов

### ♿ Доступность:

- **ARIA-атрибуты** для экранных читалок
- **Управление фокусом** в интерактивных элементах
- **Семантическая разметка** HTML
- **Контрастность** и **размеры** для удобства

Правильное применение этих принципов и техник позволяет создавать современные веб-интерфейсы, которые работают быстро, выглядят современно и доступны для всех пользователей на любых устройствах.
