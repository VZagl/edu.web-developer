## 3. Адаптивность и отзывчивый дизайн

### 3.1 Стандартные Breakpoints

Определим единую систему breakpoints для всех компонентов:

```scss
// Переменные breakpoints
$breakpoints: (
	xs: 0,
	// Мобильные (портрет)
	sm: 576px,
	// Мобильные (ландшафт)
	md: 768px,
	// Планшеты
	lg: 992px,
	// Десктопы малые
	xl: 1200px,
	// Десктопы большие
	xxl: 1400px, // Десктопы очень большие
);

// Миксин для media queries
@mixin media-up($breakpoint) {
	@if map-has-key($breakpoints, $breakpoint) {
		$value: map-get($breakpoints, $breakpoint);
		@if $value > 0 {
			@media (min-width: $value) {
				@content;
			}
		} @else {
			@content;
		}
	}
}

@mixin media-down($breakpoint) {
	@if map-has-key($breakpoints, $breakpoint) {
		$value: map-get($breakpoints, $breakpoint) - 1px;
		@media (max-width: $value) {
			@content;
		}
	}
}

@mixin media-between($lower, $upper) {
	$lower-value: map-get($breakpoints, $lower);
	$upper-value: map-get($breakpoints, $upper) - 1px;

	@media (min-width: $lower-value) and (max-width: $upper-value) {
		@content;
	}
}
```

### 3.2 Mobile-First подход

**Mobile-First** - дизайн начинается с мобильной версии, затем расширяется:

```scss
// ✅ Mobile-First подход
.card {
	margin-bottom: 16px;
	// Базовые стили для мобильных
	padding: 16px;

	// Планшеты и больше
	@include media-up(md) {
		margin-bottom: 24px;
		padding: 24px;
	}

	// Десктопы и больше
	@include media-up(lg) {
		margin-bottom: 32px;
		padding: 32px;
	}
}

// ❌ Desktop-First (не рекомендуется)
.card-wrong {
	// Стили для десктопа
	padding: 32px;

	// Переопределение для планшетов
	@include media-down(lg) {
		padding: 24px;
	}

	// Переопределение для мобильных
	@include media-down(md) {
		padding: 16px;
	}
}
```

### 3.3 Адаптивная сетка на Grid

Создаем переиспользуемую сетку для разных устройств:

```scss
// Адаптивная сетка
.grid {
	display: grid;

	// Мобильные: 1 колонка
	grid-template-columns: 1fr;
	gap: 16px;

	// Планшеты: 2 колонки
	@include media-up(md) {
		grid-template-columns: repeat(2, 1fr);
		gap: 24px;
	}

	// Десктопы: 3 колонки
	@include media-up(lg) {
		grid-template-columns: repeat(3, 1fr);
		gap: 32px;
	}

	// Большие экраны: 4 колонки
	@include media-up(xl) {
		grid-template-columns: repeat(4, 1fr);
	}
}

// Модификаторы сетки
.grid--2-cols {
	// 1 колонка на мобильных, 2 на планшетах+
	@include media-up(md) {
		grid-template-columns: repeat(2, 1fr);
	}
}

.grid--auto-fit {
	// Автоматическое размещение колонок
	grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
}
```

### 3.4 Fluid Typography

Адаптивная типографика без media queries:

```scss
// Функция для fluid типографики
@function fluid-font(
	$min-size,
	$max-size,
	$min-width: 320px,
	$max-width: 1200px
) {
	@return clamp(
		#{$min-size},
		#{$min-size} + (#{strip-unit($max-size - $min-size)}) *
			((100vw - #{$min-width}) / #{strip-unit($max-width - $min-width)}),
		#{$max-size}
	);
}

// Функция для удаления единиц измерения
@function strip-unit($value) {
	@return $value / ($value * 0 + 1);
}

// Применение fluid типографики
.heading {
	&--h1 {
		font-size: fluid-font(28px, 48px);
		line-height: 1.2;
	}

	&--h2 {
		font-size: fluid-font(24px, 36px);
		line-height: 1.3;
	}

	&--h3 {
		font-size: fluid-font(20px, 28px);
		line-height: 1.4;
	}
}

// Использование CSS clamp() напрямую
.text {
	&--body {
		font-size: clamp(14px, 2vw, 18px);
	}

	&--small {
		font-size: clamp(12px, 1.5vw, 14px);
	}
}
```

### 3.5 Container Queries (современный подход)

**Container Queries** позволяют компонентам адаптироваться к размеру родителя:

```scss
// Определяем контейнер
.card-container {
	container-name: card;
	container-type: inline-size;
}

// Компонент адаптируется к размеру контейнера
.card {
	padding: 16px;

	// Когда контейнер больше 300px
	@container card (min-width: 300px) {
		padding: 24px;

		.card__title {
			font-size: 1.25rem;
		}
	}

	// Когда контейнер больше 500px
	@container card (min-width: 500px) {
		display: flex;
		align-items: center;
		padding: 32px;

		.card__image {
			margin-right: 24px;
			width: 120px;
		}
	}
}
```

### 3.6 Адаптивные компоненты - практические примеры

#### Адаптивная навигация:

```scss
.nav {
	// Мобильная навигация (скрыта по умолчанию)
	&__menu {
		display: none;

		@include media-up(lg) {
			display: flex;
			gap: 32px;
		}
	}

	// Кнопка гамбургер (только на мобильных)
	&__toggle {
		display: block;

		@include media-up(lg) {
			display: none;
		}
	}

	// Открытое меню на мобильных
	&__menu--open {
		display: flex;
		position: fixed;
		top: 0;
		left: 0;
		flex-direction: column;
		z-index: 1000;
		background: white;
		padding: 60px 20px 20px;
		width: 100%;
		height: 100vh;
	}
}
```

#### Адаптивные кнопки:

```scss
.button {
	// Базовые стили для всех устройств
	padding: 12px 24px;
	font-size: 16px;

	// Увеличиваем область касания на мобильных
	@include media-down(md) {
		padding: 12px 20px;
		min-height: 44px; // Рекомендация Apple для touch targets
	}

	// Адаптивные модификаторы
	&--responsive {
		width: 100%; // Полная ширина на мобильных

		@include media-up(md) {
			width: auto; // Авто ширина на планшетах+
		}
	}

	&--stack {
		// Вертикальное расположение иконки на мобильных
		flex-direction: column;
		gap: 4px;

		@include media-up(md) {
			flex-direction: row;
			gap: 8px;
		}
	}
}
```
