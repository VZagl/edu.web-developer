## 2. Методы на уровне CSS SCSS

### 2.1 Базовые классы и модификаторы (БЭМ методология)

**БЭМ (Блок-Элемент-Модификатор)** - методология именования CSS классов для создания переиспользуемых компонентов.

#### Структура БЭМ:

```scss
// Блок - самостоятельная сущность
.button {
}

// Элемент - часть блока
.button__text {
}
.button__icon {
}

// Модификатор - вариация блока или элемента
.button--primary {
}
.button--large {
}
.button__icon--left {
}
```

#### Практический пример - кнопка:

```scss
// Базовый блок кнопки
.button {
	display: inline-flex;
	justify-content: center;
	align-items: center;
	transition: all 0.2s ease;
	cursor: pointer;
	border: none;
	border-radius: 8px;
	padding: 12px 24px;
	font-weight: 500;
	font-size: 16px;
	font-family: inherit;
	text-decoration: none;

	// Состояния
	&:hover {
		transform: translateY(-1px);
	}

	&:active {
		transform: translateY(0);
	}

	&:disabled {
		transform: none;
		opacity: 0.6;
		cursor: not-allowed;
	}
}

// Элементы кнопки
.button__icon {
	width: 20px;
	height: 20px;

	&--left {
		margin-right: 8px;
	}

	&--right {
		margin-left: 8px;
	}
}

// Модификаторы размеров
.button--small {
	padding: 8px 16px;
	font-size: 14px;

	.button__icon {
		width: 16px;
		height: 16px;
	}
}

.button--large {
	padding: 16px 32px;
	font-size: 18px;

	.button__icon {
		width: 24px;
		height: 24px;
	}
}

// Модификаторы стилей
.button--primary {
	background-color: #007bff;
	color: white;

	&:hover {
		background-color: #0056b3;
	}
}

.button--secondary {
	background-color: #6c757d;
	color: white;

	&:hover {
		background-color: #545b62;
	}
}

.button--outline {
	border: 2px solid #007bff;
	background-color: transparent;
	color: #007bff;

	&:hover {
		background-color: #007bff;
		color: white;
	}
}
```

#### HTML использование:

```html
<!-- Основная кнопка -->
<button class="button button--primary">
	<span class="button__text">Отправить</span>
</button>

<!-- Большая кнопка с иконкой -->
<button class="button button--large button--secondary">
	<svg class="button__icon button__icon--left">...</svg>
	<span class="button__text">Скачать</span>
</button>

<!-- Маленькая outline кнопка -->
<a class="button button--small button--outline" href="#">
	<span class="button__text">Подробнее</span>
	<svg class="button__icon button__icon--right">...</svg>
</a>
```

### 2.2 SCSS миксины и функции

**Миксины** позволяют переиспользовать группы CSS свойств:

```scss
// Миксин для создания кнопок
@mixin button-style($bg-color, $text-color, $hover-bg: darken($bg-color, 10%)) {
	background-color: $bg-color;
	color: $text-color;

	&:hover {
		background-color: $hover-bg;
	}

	&:focus {
		box-shadow: 0 0 0 3px rgba($bg-color, 0.3);
	}
}

// Миксин для адаптивной типографики
@mixin responsive-text($mobile-size, $desktop-size) {
	font-size: $mobile-size;

	@media (min-width: 768px) {
		font-size: $desktop-size;
	}
}

// Миксин для центрирования
@mixin center-content {
	display: flex;
	justify-content: center;
	align-items: center;
}

// Использование миксинов
.button {
	@include center-content;
	@include responsive-text(14px, 16px);

	&--primary {
		@include button-style(#007bff, white);
	}

	&--success {
		@include button-style(#28a745, white);
	}

	&--danger {
		@include button-style(#dc3545, white);
	}
}
```

**Функции SCSS** для вычислений:

```scss
// Функция для создания отступов
@function spacing($multiplier: 1) {
	@return 8px * $multiplier;
}

// Функция для адаптивных размеров
@function fluid-size(
	$min-size,
	$max-size,
	$min-width: 320px,
	$max-width: 1200px
) {
	@return calc(
		#{$min-size} + (#{$max-size} - #{$min-size}) *
			((100vw - #{$min-width}) / (#{$max-width} - #{$min-width}))
	);
}

// Использование функций
.card {
	margin-bottom: spacing(3); // 24px
	padding: spacing(2); // 16px
	font-size: fluid-size(14px, 18px);
}
```
