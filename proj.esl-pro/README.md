# Самостоятельная практика: проект `ESL Pro`

> Часто, особенно на фрилансе, приходится работать с макетами не по всем правилам: не такое красивое разделение слоев, нет UI kit, переменных, или адаптации. Последнее особенно интересно, так как вам могут сказать: “простую адаптацию на ваш вкус”
>
> Этот макет как раз из них. У него интересные элементы, но адаптацию вам придется сделать самостоятельно. Поверьте, такая практика вас подготовит максимально к реальной жизни.
